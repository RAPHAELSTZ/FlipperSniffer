Browser Not Supported

Web Bluetooth is required but not available in this browser.

Use Chrome on Android for the best experience.

Alternatives:

On iPhone/Safari, Web Bluetooth is not supported. You can:

• Use the "GPS Module" setting on the Flipper (hardware GPS)

• Set GPS to "Off" and scan without location

• Use the Bluefy browser on iOS (supports Web Bluetooth)

GPS data is sent directly to your Flipper via Bluetooth. Nothing goes to any server.
